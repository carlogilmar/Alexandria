# Sprint 43 — Storyboards (tiny diagram + note, many pages)

## Why

Blueprints is for *big* knowledge maps. Storyboards is the opposite tool:
a sequence of **pages**, each a **tiny diagram (mini-canvas) + a
powered-markdown note**, flipped like slides — for documenting small
things and presenting them. Validated with a mockup the user approved.

## Approach — clone-and-simplify (not a shared refactor)

We COPY the proven `BlueprintEditor` patterns into a new `StoryboardEditor`
and strip them down, rather than refactoring Blueprints (the flagship) to
be generic. Reused as-is: the combined nodes+edges `$effect` sync +
identity caches, `$state.raw`, `ConnectionMode.Loose`, the decorative
`MapTitleNode`/`MapCommentNode` (header/comment), presenter-mode CSS, and
the markdown engine for the note. New: a **pages** layer, a **note per
page**, a **filmstrip**, and a **minimal node kit**.

## Node kit (minimal, vs Blueprints' rich cards)

- `box` — small rounded rect with a one-line label. Connectable.
- `icon` — a circle with an emoji + a label underneath. Connectable.
- `header` — a big section title (reuses `MapTitleNode`). Decorative.
- `comment` — an italic margin note (reuses `MapCommentNode`). Decorative.

Only `box`/`icon` expose the four `t/r/b/l` handles; `onConnect` rejects
decorative endpoints (same rule as Blueprints). Edges are labeled dashed
connectors.

## Data model (migration `0024_storyboards.sql`)

- `storyboards(id, title, pinned, archived, created_at, updated_at)`.
- `storyboard_pages(id, storyboard_id →CASCADE, position, note TEXT,
  created_at, updated_at)` — the ordered slides; the markdown note lives
  here.
- `storyboard_nodes(id, page_id →storyboard_pages CASCADE, kind CHECK(box|
  icon|header|comment), label, icon, color, content, x, y, width, height,
  timestamps)`.
- `storyboard_edges(id, page_id →CASCADE, source_id/target_id
  →storyboard_nodes CASCADE, source_handle, target_handle, label,
  timestamps, UNIQUE(source_id,target_id))`.

`get_storyboard` returns `{ storyboard, pages, nodes, edges }` (all pages'
nodes/edges at once); the editor filters by the current page. Canvas
mutations bump the storyboard's `updated_at`; note edits bump the page.

## Layout

`StoryboardView` (index) → `StoryboardEditor`: toolbar (title · Present ·
Export · page count) → the current page = **mini-canvas on top** +
**markdown note below** → a **filmstrip** of page thumbnails + an **Add
page** tile. Present = a slideshow of canvas+note per page (←/→, Esc).

## Entry point

⌘1–8 are taken, so Storyboards is reached via the **command palette**, a
**sidebar/Summary** entry, and `storyboard:id` as a first-class entity
link — no new digit shortcut (webview reserves too many).

## Follow-ups (same sprint)

- **PNG export shipped**, Present removed. The toolbar's "Export image"
  button opens the Blueprints-style **crop-rectangle** flow (pre-fit to
  content, drag/resize, Save PNG or Copy), reusing `composeCropPng` /
  `buildEdgeLayerSvg` (no image-inlining — storyboards have no pasted
  images). The composed PNG stamps `"<title> · page N"`. Present mode was
  dropped (the user didn't need it); `←/→`/Esc present-nav removed.
- **Filmstrip controls fixed**: they were clipped (an `overflow-x` scroller
  clips the other axis too, and the buttons poked above the tile). Slides
  are now `overflow-hidden` tiles with the page number top-left and a
  clean dark **control bar (‹ › ×) along the bottom of the active slide**.
- **Icon set** (Lucide concept icons + Devicon brand logos): the icon
  node's `icon` field still stores a string — now either a key into
  `$lib/storyIcons.ts` (`box`, `database`, `b:docker`, …) or freeform
  emoji/text. `StoryIconNode` renders concept icons as `currentColor` line
  SVGs (tinted by the node accent) and brand logos as their multi-color
  `-original` SVGs, and has a **picker popover** (Concepts / Logos tabs +
  search + an emoji field + Clear). `storyIcons.ts` is generated by
  `scripts/gen-story-icons.mjs` from `lucide-static` (ISC) + `devicon`
  (MIT) — those are one-off deps, NOT kept in package.json (the generated
  file is self-contained), so regenerating means installing them
  temporarily (see the script header).

## v1 scope / deferred

v1: full entity + page + node/edge CRUD, the canvas+note page, the four
nodes, the filmstrip (add/delete/reorder/navigate), and **Present**.
Deferred to a fast-follow: **PNG export** (the crop-rectangle composer),
per-node drag-reorder niceties, an icon *picker* beyond typing an emoji.
